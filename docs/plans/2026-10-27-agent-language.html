Preregistration

Bars: oracle must reject every planted semantic failure and accept every reference before inference; no language winner from small pilot. Compare final functional success, cost and latency; report Wilson intervals. Arms: identical model IDs/settings across languages; three independent pilot trials, maximum two repairs, 8192 output tokens. Paid inference cap: $10, reserve worst-case tokens before every request; stop on missing prices, auth/credit failure, unknown charges or cap exhaustion. No private held-out data: synthetic development tasks only; all reference programs are visible to the implementer but excluded from generation prompts. Decoys cover invalid syntax, types, semantics and authorization. Expand promising arms to 30 trials only within the cap and after validating the pilot.

Risks and verification

BAML version numbers differ from the v1 language label. Test actual source compilation and workerd interoperability. Keep unsupported workloads outside comparable denominators. Host type injection can shift diagnostics or reject legitimate syntax: test declaration-only versus JSDoc approaches and preserve generated JavaScript bytes for execution. Resource and security limits belong to the host, not the language.
