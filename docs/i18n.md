# Frontend i18n (lightweight KO/EN)

Workshop UI copy lives in `packages/workshop-frontend/src/i18n/`:

- `en.ts` — English source catalog (default keys)
- `ko.ts` — Korean UI catalog
- `useT()` / `I18nProvider` — runtime lookup with `{var}` interpolation
- Locale persisted as `cfos.locale`; supported browser preferences are used on first visit, with English as the fallback.

## Product nouns (Korean UI)

Nav and page chrome use Korean product nouns for consistency:

| EN | KO |
| --- | --- |
| Workspace(s) | 워크스페이스 |
| Blueprint(s) | 블루프린트 |
| Output(s) | 출력 |
| Gatekeeper(s) | 게이트키퍼 |

## Backend / package metadata overlays

Some user-visible strings arrive from the API or gatekeeper packages (not hardcoded in the SPA). Overlay them at the **display boundary** via helpers in `localizeDisplay.ts` — do not mutate stored/API values.

| Source | Helper | Catalog keys |
| --- | --- | --- |
| Featured / format blueprint title & description | `localizeBlueprintDisplay()` | `featuredBlueprints.<id>.*`, `featuredBlueprints.byTitle.<slug>.*` |
| Format output nouns (`Doc` / `Slides` / `Sheet` / `App`) | `localizeFormatOutput()` | `formatOutput.byId.*`, `formatOutput.byNoun.*`, `formatOutput.byPlural.*` |
| Gatekeeper vendor displayName + tagline + description | `localizeVendorDisplay()` | `vendors.<id>.*`, `vendors.byTitle.<slug>.*` (id = `GATEKEEPER_*` suffix, lowercased; hyphen/underscore) |
| Gatekeeper SupportedResource title + description | `localizeSupportedResource()` | `gatekeeperResources.byTitle.<slug>.*` |
| Gatekeeper management app titles (`providesUi.title`) | `localizeGatekeeperAppTitle()` | `gatekeeperApps.<id>.title`, `gatekeeperApps.byTitle.<slug>.title` |
| Connected-account / connector product defaults | `localizeAccountDisplayName()` | `accountDefaults.*` + English vendor-name prefix → `vendors.<id>.displayName` |

Unknown / user-authored values (custom published blueprints, OAuth profile names, workspace-specific Notion titles, MCP portal host-specific taglines without a catalog key) stay in the language returned by the backend.

Composer capsules that insert `format.output.noun` into agent-bound message text are **not** overlayed — those strings leave the UI and must stay machine-stable.

## Adding strings

1. Add the key to **both** `en.ts` and `ko.ts`.
2. Replace hard-coded UI text with `t('section.key')`.
3. For API-backed display fields, prefer a frontend overlay map keyed by stable id rather than translating package source in this fork’s UI-only i18n track.
