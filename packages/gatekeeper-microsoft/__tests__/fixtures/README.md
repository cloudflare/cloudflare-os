# Test fixtures

Each fixture is generated by the script beside it (run instructions in its header); regenerate rather than hand-edit.

- `openpyxl-rich.xlsx` (`make-openpyxl-rich.py`, openpyxl 3.1.5): a workbook with what the Excel writer can't make (a second sheet, a table, a chart, conditional formatting, data validation, a comment, merged cells, a hyperlink, a named range, custom formatting), for `xlsxFeatures`. openpyxl writes SpreadsheetML as Excel reads it, but it isn't Excel.
- `python-docx-report.docx` and `python-docx-template.dotx` (`make-python-docx.py`, python-docx 1.2.0, whose default template Word authored): a report (split runs, list styles, a styled table, header and footer, a picture, a comment, colored text) for `editDocx` and `docxFeatures`, and a corporate template (Georgia, a dark-red Heading 1, wider margins, its own header and footer) for `markdownToDocx`'s template mode.
- `python-pptx-deck.pptx` and `python-pptx-template.potx` (`make-python-pptx.py`, python-pptx 1.0.2, whose default template PowerPoint authored): a deck for the PowerPoint writer and editor with a title slide with a transition, a slide whose first paragraph is split across differently formatted runs and which has speaker notes, a table slide with an animation, a picture and a chart; and the same design saved as a .potx with two slides of its own (one with notes, one with a picture) that a deck made from it must drop.
- `mail/`: message bodies (Outlook-authored HTML, a reply chain, a newsletter, phishing, prompt injection, right-to-left text) for `outlook-content.test.ts`.
